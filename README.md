# browser-console-scripts

一些可以 **直接在浏览器控制台（Console）中运行的 JavaScript 脚本合集**。

本仓库主要用于存放无需安装环境、无需插件，复制后即可在浏览器中执行的小脚本，
适合用于自动化操作、行为测试、学习与研究等场景。

---

## 使用方式

1. 打开目标网页
2. 按 `F12`（或右键 → 检查）打开开发者工具
3. 切换到 `Console`（控制台）
4. 粘贴对应脚本并回车执行
5. 如有说明，首次可能需要手动触发一次操作
